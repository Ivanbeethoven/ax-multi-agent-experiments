27 次操作分为：open 5、read 9、write 6、close 5、fsync 1、rename 1。read 包含 EOF 调用，实际字节按返回值累加，不按申请的缓冲区长度累加。本次修改后的文件为 21,012 字节，所以实际写入比此前 1.7 KB 的补丁大；补丁大小不能代替写入量。

重复读取按**同一文件、同一段内容是否已经读过**计算。本次修改前的源文件被检查和编辑步骤各读一次，第二次的 20,357 字节计作重复读取。部分写入会使对应区间失效；rename 保留文件身份；新文件即使内容相同也不算原文件的重复读取。它不是页缓存命中率，也不是磁盘读取比例。

## 开跑前已通过的检查

预检在独立空目录执行，已知结果为读 10 字节、写 5 字节、重复读 5 字节。覆盖短读、EOF、部分重叠、写后再读、rename 后继续用 FD 读、ENOENT。只有采集统计、Rust 回放和最终树都一致，才写入 `preflight-gate.json` 并准备任务仓库。

任务开始时间晚于预检通过时间。16 项解析/计数测试通过。另实际验证旧的模型运行入口在没有合格文件采集器时拒绝启动，未创建 Agent 容器或调用模型，见 `agent-start-blocked.txt`。

开发期间有两项问题被校验发现：

- 扩展未知操作检查后，曾把 `getrandom` 的随机字节误当路径；预检失败，任务没有启动。失败记录保存在 `preflight-failure-before-task`，修复后重新执行得到本目录结果。
- 对初始归档使用 Python 默认安全解压时，目录权限从 0777 变为 0755，初始树检查拒绝回放。现在使用安全路径检查，同时保留归档中的普通 rwx 权限；已经从归档独立解压、回放并核对最终树，见 `portable-check.json`。

## 保存的材料

- `task-capture/strace.log`：原始系统调用记录，含实际读写内容。日志放在工作区外。
- `task-capture/trace.jsonl`：Rust 输入；写入字节为 `data_hex`，读取保存预期字节数和 SHA256。
- `task-capture/syscalls.jsonl`、`metrics.json`：原始操作、偏移、返回长度与统计。
- `initial-workspace.tar.gz`：完整初始仓库，包括 Git 数据和许可证；约 19.5 MB，独立回放不需要 Docker 镜像。
- `result.json`、`task-replay.json`：采集与回放核对结果；源文件还与此前通过评分的 Agent 补丁逐字节一致。
- `probe-capture/`、`probe-replay.json`：实际预检证据。
- `provenance.json`、`capture-tests.txt`、`artifacts.sha256.json`：版本、脚本摘要、测试与文件校验值。

## 独立复现回放

在 Linux 上编译独立仓库 `fuse-workload-replay` 的 `8e1422904feb6268dad3cb4a4e2a6bd668002031`，然后在实验仓库运行：

```bash
python3 scripts/replay_fs_trace_bundle.py \
  --bundle results/fs-trace-pytest-10356-20261023 \
  --output /home/hxy/ax-fs-trace/replay-new \
  --binary /path/to/fuse-replay
```

输出目录必须不存在。脚本先验证结果包摘要，安全解压并保留普通权限，再调用 Rust。Rust 会检查初始文件树、每次 read 的内容，脚本最后检查最终树和字节总数。新增采集运行方法见 [脚本说明](../../scripts/fs-trace.zh.md)。

## 能说明什么

本次证明小范围采集链路能保存足够的信息，计算实际读写量、操作次数和重复读取比例，并交给现有 Rust 程序正确回放。没有用脚本预设数字代替采集结果。

采集目前限定单进程、受支持的 POSIX 操作；工作区外的 Python/库 I/O 单独列为排除项，完整 OpenCode 状态没有包含。遇到工作区内 mmap、向量 I/O、目录枚举、锁或子进程等未支持情况会拒绝转换。完整 Agent 采集仍待接通。

运行在 WSL ext4，预先扫描会暖缓存，strace 本身也增加开销。这里的字节是应用返回字节，**不是磁盘/云存储物理流量，也不是 FUSE 协议计数**。本次操作数很小，不用于比较存储性能；不会用这 21.42% 外推所有 Agent。
