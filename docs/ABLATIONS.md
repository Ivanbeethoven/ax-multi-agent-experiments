# 保留的功能比较

| 比较 | 位置 | 固定内容 | 变化 |
|---|---|---|---|
| Dynamic | 第 1 组四种 fio；第 3 组 Packed；第 4 组 64 Agent | 客户端版本、机器、缓存、负载、种子 | 修改版 RustFS 9000 / 原版 RustFS 1.0.5 的 19000 |
| 对象块尺寸 | 第 1 组随机读、随机写 | 应用请求、子块读取、并发和缓存 | 自动选择 B、固定 64 KiB、4 MiB |
| Packed | 第 3 组 | 10 万文件、32 读者、相同内容与资源 | Native 与 Packed |
| 整包缓存 | 第 3 组 Packed | 其他配置不变 | 整包缓存开启/关闭 |
| Overlay 开销 | 第 2 组 | 同一系统、相同初始内容和读写顺序 | 直接父工作区与 fork 子工作区 |

每个条件运行一次。读取时记录首次冷读和后续读取，写入同时记录应用完成与上传完成。Dynamic 各组重新写入对象并记录实际 B/q。

完整参数见 [实验方案](PLAN-REVIEW.md)。
