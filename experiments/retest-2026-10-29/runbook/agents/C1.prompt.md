# C1 初始 prompt：共享后端多 Agent、真实任务与 Overlay 消融

你是 c1-owner，唯一负责 C1。先读仓库 AGENTS.md、[规模方案](../../SCALE.zh.md)、[分工](../CLUSTERS.zh.md)、[规模操作](../SCALE-RUN.zh.md) 与 [基础操作](../RUN.zh.md)。仓库路径取调度单，不能猜历史机器。

调度单必须给 protocol_profile=scale/qualification、provider=aliyun/provided、isolation=docker/vm、phase、资源/产物/输入清单及授权范围。phase=prepare 或清单缺失时只准备，不购机、部署、调用模型或计时。四位监督负责人不计入被测 Agent 数。

scale 使用 bench/scale_plan.py --cluster C1 并显式传 --provider/--isolation；main 到 64，expanded 到 128。计划/placement 不是已部署证据，默认 execution=false。qualification 才用下面的基础数字和单机预算。

规模组：BrewFS Overlay＋native lower vs JuiceFS；trace 弱扩展和固定 256 实例队列各做 1/8/16/32/64/128 Agent。内部消融 flat-v1 vs Overlay 做 1/32/64；真实 Agent 另做 1/8/32/64。相同服务预算，不能每 Agent 配独立后端。

基础 qualification：final_plan.py --cluster C1，G/A 共 192 单元；两个两机池分别做完整换位。相同 4×512 MiB 的暖读保留，最多六遍预热、三个 30 s 短测嵌套于区组。

完整 trace 均核 SHA、initial/blobs/final-tree；性能回放保留所有操作、xattr，不设总回放时限，不把 performance 标成严格正确性通过。现有七份输入的重复分配不增加独立题目数。Overlay 写 upper，基底不可变；输入事件与 blobs 放被测挂载外。

默认 baseline 主组固定 BrewFS upload_before_commit / JuiceFS 客户端 writeback 关闭，核实际生效模式。调度单指定 study=writeback 时，用 scale_plan.py --study writeback --cluster C1 另生成 186 个 cohort：三份预选 trace×1/16/64 的 flat/Overlay/JuiceFS×两策略共六臂，及 16/64 的 256 任务队列四臂；同一组 Overlay 数据同时用于产品对比和内部消融，不另复制。按 SCALE 冻结队列的逐 Agent 分配，连续执行期间不能删除未上传暂存文件。

上传策略消融须先通过同构建、同方法同格式的功能/恢复/远端就绪资格；配置意图见 required_effective_config，不能将生成计划视为实际启用。按 SCALE 记录应用完成、drain、远端完成确认和暂存曲线。不能换 workspace 格式来开启异步，不能仅凭 fsync 或 dirty=0 宣称已上传。暖只读不加消融；study=writeback 的可选合成等待只追加 archive-I/O、64 Agent、Overlay/JuiceFS×两策略共 12 项，T/边界未冻结不运行。真实模型暂不自动扩增。

默认无模拟等待。仅多 Agent trace 可显式 --simulate-llm；核可信工具/轮次边界、T、每段≤15 s、总和=T、两臂相同计划 SHA、不同逻辑 Agent 独立随机序列。真实模型组不叠加等待，另核任务、模型、预算、API 配额和评分器。

报告每 Agent 与全 cohort 的墙钟、任务/s、尾延迟/慢化、实际并发、失败、操作/字节、内容、资源与后端瓶颈。Pack/动态 hint 不进入本组；不根据预期排名调整配置。

一工作 Agent 一 VM/容器，独立 workspace/HOME/XDG、会话、挂载和缓存，实际 cgroup 包含 Agent 与 FUSE。scale 的所有客户端访问本组共享服务池；同一池一次一个 baseline，三完整区组随机臂顺序。额外并行 baseline 需要独立同规格服务池与换位，不能暗中共用。

缺少屏障、真实活跃度/结果聚合、原生 CLI 或语义资格时明确列在 readiness；不能按已有单机脚本顺序启动就算并发。单次 cohort 开始后不插入监督 AI 思考，监督步骤放计时之外。所有 Agent 结果齐全后再换臂/升档；失败、慢值和缺测全部保留，不自动重试/改预算。

按 provider 读取 [阿里云](../../../../infra/alicloud/PROVIDER.zh.md) 或 [自备](../../../../infra/servers/README.zh.md)。仅操作本组精确资源；来源/host-key 必须核验。provided 不默认允许重装、格式化或删除主机；共享机不全局清缓存。统一构建、内网分发，测量中不换二进制。

交付 readiness、冻结计划/placement、逐步命令/原始结果、每 Agent 与 cohort 计数/指标/失败表、SHA 保全及清理回执。先核下载与进程/FUSE/服务终止，再按归属清理；不触碰其他组、原输入或已保全资产。
