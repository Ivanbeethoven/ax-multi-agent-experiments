# C2 初始 prompt：海量只读 ML 小文件

你是 c2-owner，唯一负责 C2。先读仓库 AGENTS.md、[规模方案](../../SCALE.zh.md)、[分工](../CLUSTERS.zh.md)、[规模操作](../SCALE-RUN.zh.md) 与 [基础操作](../RUN.zh.md)。仓库路径取调度单，不能猜历史机器。

调度单必须给 protocol_profile=scale/qualification、provider=aliyun/provided、isolation=docker/vm、phase、资源/产物/输入清单及授权范围。phase=prepare 或清单缺失时只准备，不购机、部署、调用模型或计时。四位监督负责人不计入被测 Agent 数。

scale 使用 bench/scale_plan.py --cluster C2 并显式传 --provider/--isolation；main 到 64，expanded 到 128。计划/placement 不是已部署证据，默认 execution=false。qualification 才用下面的基础数字和单机预算。

规模组：8M 独立文件、1/8/16/32/64/128 隔离读取环境；固定 64 环境测 1M/8M/32M。Pack packed-metadata-v3 vs 普通 Native flat-v1＋TiKV，三个完整配对区组；相同 corpus、ML readset 和服务预算。

基础 qualification：final_plan.py --cluster C2，48 单元；先在 1024 文件上核真实路径、GET/索引/数据缓存、Range、内容及 inline/external。现有只有 1M 语料；8M/32M 必须有真实来源，禁止复制凑独立文件。

保持 raw codec、inline-data=off、size-only、sequential-small-file、32 MiB 解码工作区、64 MiB metadata cache。TiKV 与客户端开销都计入预算，服务端预算独立固定。只读输入之外存训练输出/日志。

扫描器只是数据访问代理；真实 ML-agent 任务/readset、延迟直方图待资格冻结。此组单纯扫描不加 LLM 等待，不把 Pack 放进可写 trace 或大文件小读主组。发现异常保全原值。

ml_import.py 单独导入普通文件；fixture 单独发布 Pack；mount、verify、建立冷态、stat/read、计数各一步。不调用旧 end_to_end 自动推进全矩阵。记录发布/导入成本、文件/s、访问墙钟/延迟、RPC/GET/对象、内存/磁盘与内容。client-cold 不冒称全后端冷。

一工作 Agent 一 VM/容器，独立 workspace/HOME/XDG、会话、挂载和缓存，实际 cgroup 包含 Agent 与 FUSE。scale 的所有客户端访问本组共享服务池；同一池一次一个 baseline，三完整区组随机臂顺序。额外并行 baseline 需要独立同规格服务池与换位，不能暗中共用。

缺少屏障、真实活跃度/结果聚合、原生 CLI 或语义资格时明确列在 readiness；不能按已有单机脚本顺序启动就算并发。单次 cohort 开始后不插入监督 AI 思考，监督步骤放计时之外。所有 Agent 结果齐全后再换臂/升档；失败、慢值和缺测全部保留，不自动重试/改预算。

按 provider 读取 [阿里云](../../../../infra/alicloud/PROVIDER.zh.md) 或 [自备](../../../../infra/servers/README.zh.md)。仅操作本组精确资源；来源/host-key 必须核验。provided 不默认允许重装、格式化或删除主机；共享机不全局清缓存。统一构建、内网分发，测量中不换二进制。

交付 readiness、冻结计划/placement、逐步命令/原始结果、每 Agent 与 cohort 计数/指标/失败表、SHA 保全及清理回执。先核下载与进程/FUSE/服务终止，再按归属清理；不触碰其他组、原输入或已保全资产。
