## 4. dynamic block

| 结论 | 证据 |
|---|---|
| **默认配置下是 no-op** | `DEFAULT_EC_BLOCK_SIZE = 1024×1024`（`ec_block_layout.rs:13`）；EC 2+2 时 shard = 512 KiB = frame 大小 → 标记永不写入 |
| 影响 | 该特性在本批配置下**无法生效**，任何「dynamic block 收益」都无从谈起 |
| 下一步 | B = 256 KiB / 512 KiB / 1 MiB × 文件大小分档 × EC 2+2 / 4+2 |
