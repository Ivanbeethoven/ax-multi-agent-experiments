每台先按云盘序列号在独立挂载命名空间只读清点，保全旧 C1 待归档的证据和原部署、失败及[最近一次 A→B 迁移回执](../c4-state-reopen-a-b-result-01/README.zh.md)。旧 C2–C4 已有盘外结果；对象节点仅排除能从已固定的输入与脚本重建的测试数据，三个额外确认的桶有[来源路径与 SHA](objects.generated-bucket-pins.json)。未识别路径必须处理至零才能进入归档。元数据和对象服务没有启动；原测试输入与 OSS 未修改；协调盘原有证据保留。
