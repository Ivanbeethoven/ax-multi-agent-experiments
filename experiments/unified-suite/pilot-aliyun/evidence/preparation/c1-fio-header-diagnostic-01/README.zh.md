# fio 的 CRC 校验头

C1 两臂的最终整文件 SHA 不同，分别通过完整冷读 CRC。为区分 fio 自身生成的字节与文件系统写坏的字节，在本机用同版本 `fio-3.36` 和同一 4 MiB 初始文件重跑两次。读写计数相同，末态共有 1,956 个不同字节，均位于各 4 KiB 校验块的时间字段或头 CRC 字段；数据区相同。[fio 3.36 的实现](https://github.com/axboe/fio/blob/fio-3.36/verify.c#L1093-L1107)会写入请求时间，再计算校验头 CRC。

[原始回执](receipt.json) · [复用脚本](check.py)。这个本机诊断解释整文件 SHA 为什么可能不同。云上没有保存两份完整末态数据供逐字节对比，仍以两臂各自的冷读 CRC 和实际操作记录为准。
