# 32 Agent 正式实验：回放节奏、地域和云盘

本页保留 2026-11-11 的询价记录和容量计算方法；当前路线、负载与资源参数统一见[新方案](current/README.zh.md)。报价需在建机前刷新，原 pilot worker 的能力不能视为新多机调度已实现。

这份手册用于复跑。并发上限 **32**，主档 8/16/32；完整 trace、百万文件和配对重复保留。元数据主线固定 Redis，不把 TiKV 当作自动替代。32 是本轮资源与测量上限；Agent 数不等于元数据并发请求数，实际用 Redis 命令/秒、P99、CPU、AOF 等待和排队判断瓶颈。

## C2：只错开 Agent 启动，不在每次 I/O 后加随机 sleep

| 条件 | 配置 | 用途 |
|---|---|---|
| 主表：同步突发 | 所有人准备好后同时释放；`pacing=off`，不传 `--simulate-llm` | 在固定输入下比较存储峰值和扩展。8/16/32 各用相同的 pytest-full-02 全量 trace |
| 次表：启动错峰 | 只在 32 档加一组，启动偏移固定在 **0–2 秒**；将窗口均分为 32 格，每格启动一个，随机打乱 Agent 与格的对应关系。首格在 0 ms 启动，其余格内按固定种子取偏移；典型启动节奏约 16 个/秒。运行中不插入等待 | 判断主表差距是否受同时起跑影响，不声称复现真实模型节奏 |
| 可选：工具边界等待 | 只有拿到经核验的工具/轮次到 FUSE seq 映射才做。先用合成总量 `T=min(K × 1 秒, 30 秒)`（K 是已核实边界数，至少 2），现有生成器随机分配，每段可在 0–15 秒，总量固定。未核验映射就不跑此项 | 测带间歇的存储访问；不猜空闲段、不把合成等待当模型延迟 |

补充混合批次只做 **32 Agent**，起步固定 pytest 10、Django 2、ripgrep 10、archive I/O 10，合计约 **2.01 亿回调**，四种都完整回放。Django 单条约 5,779 万回调，不用简单四等分，也不把混合结果和同质扩展曲线拼在一起。首选先测同质曲线，再跑混合；混合的分 trace 延迟单列，Django 样本少不单报 P99。

每个配对批次冻结同一 Agent→trace 表、workspace 身份、种子和偏移 JSON 的 SHA256。offset 从共同 barrier 释放计；预检、挂载、输入校验在 barrier 前。记录计划偏移、实际启动、完成、启动误差和峰值同时运行数。同步和错峰分别报告整批 makespan（含启动等待）及逐 Agent 实际回放耗时。错峰不是“32 始终同时忙”，用实际重叠度和实际 RPC 报告。工具等待额外记录实际 sleep 和扣除 sleep 的回放墙钟，两者都不是纯 I/O 时间。

```bash
python3 bench/trace_start_schedule.py --agents 32 --seed 9173 \
  --mode staggered --output "$RUN/c2-start-r01.json"
```

该命令只产出偏移表。现有 C2 主协议只接受 `pacing=off`，并且 Aliyun pilot worker 只支持单 Agent；多机调度器须先接入偏移表并验证共同 barrier、启动误差和两臂表一致，再跑错峰。现有 Rust `--simulate-llm` 属于另一项机制，见[工具等待说明](../../tools/full-fuse-replay/THINK-TIME.zh.md)。

## 地域：按完整一池报价，再算换地域成本

2026-11-11 只读实询。统一报价篮子：4 台 32C128G 客户端、5 台 16C64G 后端（1 Redis + 4 RustFS）、全节点 40 GiB PL0 系统盘；数据盘客户端各 100 GiB、Redis 60 GiB、RustFS 每台 4×120 GiB，数据盘均 PL1。同一个地域/机型的数字由 ECS `DescribePrice` 返回；选两种规格均显示 WithStock 的区，未预留库存。

| 地域及机型 | 完整单池 ¥/小时 | 现有条件 |
|---|---:|---|
| 乌兰察布 B / 河源 C，u2a | **43.752** | 本次询价并列最低；另计网络和数据预置 |
| 乌兰察布 B，u1 | 43.896 | 同机型与杭州 J 可直接比报价 |
| 杭州 B，u2a | 48.016 | 现有 VPC 只查到 J 区交换机，B 区需准备私网子网，先核跨区管理链路 |
| 杭州 J，u1 | 52.176 | 可复用原跳板和私网，杭州 OSS 可走同地域内网 |
| 杭州 J，g7 | 59.794 | 作为预算上界参考 |

**短批先杭州，长批优先复核乌兰察布或河源。** 对相同 u2a，外地比杭州 B 省 ¥4.264/池小时；若预计运行 8 池小时，只省约 ¥34.11。对相同 u1，乌兰察布比杭州 J 省 ¥8.28/池小时，8 池小时省 ¥66.24。只有额外网络、跳板、数据预置及部署计费时间低于节省额才换区。四份 C2 输入压缩合计 **8,788,424,165 B（约 8.18 GiB）**；只复制所需输入、构建包，生成语料在当地生成。复制一次到当地 OSS 并核 SHA，后续私网复用；原杭州 OSS 保留。另计云盘峰值、OSS 请求/结果、流量和跨区链路。两系统的一对样本必须用同池同机型；不把跨地域价格差当性能差。参见 [ECS 实时报价接口](https://www.alibabacloud.com/help/en/ecs/developer-reference/api-ecs-2014-05-26-describeprice)和 [OSS 内网计费](https://www.alibabacloud.com/help/en/oss/user-guide/traffic-fees)。

## 云盘：给每种盘单独定容量、性能和寿命

| 盘与用途 | 32 档询价基线 | 开机/扩盘前必核 |
|---|---:|---|
| 系统盘 | 9×40 GiB PL0 | 仅 OS 和工具；不放 trace、对象和大日志 |
| 客户端输入/暂存 | 4×100 GiB PL1 | 按每台分配的完整压缩包、解压后 trace/blob、解压临时双份、写暂存和原始日志核算。确认不影响回放时可改 PL0，但两臂相同；先把输入校验和大文件复制移到计时窗外 |
| Redis 持久化 | 1×60 GiB PL1 | AOF 现有大小 + rewrite 临时文件及可能的 RDB；单独核 Redis 实际内存、fork/rewrite 峰值、写延迟和磁盘剩余。不要把可用内存当磁盘容量 |
| 四节点 RustFS | 16×120 GiB PL1 | 以真实纠删码/盘组、最满盘和 inode 为准；测对象封装、每盘实际写入放大、重启读回、校准及失败现场。备选少盘方案须新拓扑资格与独立配对，不自动用单盘节点代换 |
| 协调盘、跨机目标 | 另列 | 协调盘按状态库、原档汇总和验证副本单列，原始包上传并校验后回收临时空间。目标机只在跨机批次开，按额外客户端报价 |

实询四地 120 GiB PL0/PL1 分别 **¥0.126 / ¥0.252 每盘小时**。询价篮子的 2,380 GiB PL1 数据盘合计 **¥4.998/小时**，其中 RustFS 16 块盘占 **¥4.032/小时**。每块对象盘从 120 增到 240 GiB，全池多 **¥4.032/小时**（按该线性单价估算；扩盘时重新询价）。全部对象盘改 PL0 约省 ¥2.016/小时，但可能把结果变成云盘瓶颈，不能只为省钱在主对照中降级。按 [ESSD 性能规格](https://www.alibabacloud.com/help/en/ecs/user-guide/block-storage-performance)，容量、单盘和实例的 I/O 限额都要核，不能用档位宣传的最高值代替实测。

每个池开机前生成**逐盘**预算表：盘角色、GiB/PL、设备与挂载、当前 bytes/inodes、base 导入增量、每个校准/正式副本增量、AOF/归档峰值、保留失败副本、预计占用小时。正式尺寸按 `所需 GiB ≥ 峰值占用 / 0.8` 向上取整，每盘与 inode 都留 20%；增量以真实预检或保守上界为准，不把逻辑数据量直接当物理容量。C4 32 个全拷贝加父目录一轮是 **135.168 GB** 逻辑量；保留两轮、校准或失败目录须叠加计。四条规则：

1. 用预留的新盘短测与负载相关的随机 I/O、顺序吞吐和 fsync，并核实例限速；不在正式卷上做破坏性写测试。开始正式配对前固定相同盘规格、设备布局和耐久设置。
2. 16 档和 32 档分别记录 per-disk IOPS/带宽、延迟、队列深度、利用率和节流，以及 Redis AOF/fsync、RustFS 物理读写与网络。看到瓶颈先辨认云盘、ECS 聚合限速还是应用层；扩盘/换 PL 后另开配对，保留旧结果。
3. 导入前、测量前、每轮结束检查剩余字节和 inode；任一盘预测低于 20% 余量则不开始下一轮。校准子目录只有在原始证据读回通过且原租约和进程已关闭后才按批准的回收方案清理；共用父目录、活动卷及已有 OSS 不删。
4. 为每块本轮云盘登记创建、挂载、随实例释放标志及实际释放确认时间。核验归档后释放空池和它的盘，查云 API 确认；不把停机、脱盘或释放请求视为费用终止。
