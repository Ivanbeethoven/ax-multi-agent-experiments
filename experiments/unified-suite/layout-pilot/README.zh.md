# 布局预研图

`data/2026-11-11/ratios.json` 保留原 Figure 5 的全部 18 项汇总，不与 10K 小文件批次混合。绘图不生成新的观测值。

    python render.py --paper <论文仓库根目录>

输出：论文 `figures/pilot/layout-comparison.pdf`、可编辑 SVG、PNG，以及正文使用的 `layout-values.tex`。Python 只负责绘图；测试工具不变。

- (a) 后端冷 Range 读：批量读取 / 原读取路径。柱体到最小值，斜线顶段到最大值；这是不同请求窗口的范围，不是置信区间。
- (b) CPU 时间：数据原为 baseline/candidate，绘图取倒数得到 candidate/baseline；越低越好。
- (c) 客户端冷随机读：稀疏读取与布局提示 / 默认策略。
- (d) 客户端其他负载：保留接近持平的结果和写入回退。四个面板在单栏内排成 2×2，上排后端 (a,b)、下排客户端 (c,d)；(d) 改用横向柱，保留七项负载的标签与数值。线性坐标从零开始，虚线基准为 1。图注保留控制负载的读写大小。
- 图中 14 项；另外 4 项后端整对象/全 warm 汇总移到相邻正文，由同一 JSON 生成宏。18 项全部保留，没有按结果好坏筛选。
- 后端 8 个配对周期；客户端 cold 使用环境退化前的 2 个周期，warm/mixed 使用 8 个周期。当前只有汇总数据，不推算方差。

更换批次时新增日期目录，用 `--data <新 ratios.json>`。若获得每周期数据，应新增配对统计与区间计算，不能把当前跨 workload 的范围当作重复测量区间。

复核可传 `--qa-tools <nature-figure/scripts>`；对齐报告写入论文 `validation/layout-pilot/`，并检查最终 PDF 字体、碰撞和论文内缩放效果。

单栏 2×2 版画布为 240 × 210 pt，按栏宽插入，字号保持 8.3–9 pt。四个数据区等宽等高，无对齐豁免；(a) 横轴为 coding-block size，见图注。18 项数据、显示数值的四舍五入口径、归一化基准和区间含义保持一致。
